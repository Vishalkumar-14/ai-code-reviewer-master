# Code Review Crew

**Multi-Agent AI Code Review Platform powered by Gemini and Google Cloud**

Built for the Gemini + Google Cloud Hackathon 2026

---

## Overview

Code Review Crew is a multi-agent AI-powered code review platform that analyzes source code from multiple perspectives and generates a comprehensive review report.

Instead of relying on a single AI model, Code Review Crew orchestrates multiple specialized review agents that work together to identify bugs, security vulnerabilities, performance bottlenecks, and code quality issues. Their findings are aggregated by a Lead Judge Agent to produce a final confidence-scored review.

### Key Features

* 🤖 Multi-Agent Architecture
* 🔒 Security Analysis Agent

---

## Agent Architecture

### 🔒 Security Agent

Identifies security vulnerabilities, insecure coding practices, authentication issues, and potential attack vectors.

### 🐞 Bug Detection Agent

Analyzes business logic, edge cases, runtime errors, and code correctness.

### ⚡ Performance Agent

Detects inefficient algorithms, bottlenecks, excessive memory usage, and optimization opportunities.

### 📝 Code Quality Agent

Evaluates readability, maintainability, coding standards, documentation quality, and best practices.

### 👨‍⚖️ Lead Judge Agent

Aggregates findings from all agents, calculates confidence scores, prioritizes issues, and generates the final review report.
